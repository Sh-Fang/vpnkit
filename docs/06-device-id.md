# 06 · 设备标识

服务端用设备标识做绑定。本项目的目标之一是**让标识稳定**，避免因硬件变化反复被要求重新登记。

## 1. 输出格式

```
32 位大写十六进制字符串（16 字节摘要的 hex 表示）
例：3F2A9C14B7E08D5612AB44CD990E7F31
```

## 2. 取值优先级

按顺序尝试，**第一个成功的就用**：

| 顺序 | 来源 | 说明 |
|---|---|---|
| 1 | 本地缓存 | 存在即直接用，不再计算（保证稳定） |
| 2 | 网卡 MAC 列表 | 排除回环与虚拟网卡，按接口序号排序后拼接 |
| 3 | 系统盘卷序列号 | 前两者都拿不到时的兜底 |

### 2.1 MAC 列表的规范化

1. 枚举所有网卡，只保留**物理网卡**（排除 loopback、`utun`、`bridge`、`vmnet`、`vEthernet` 等虚拟接口）
2. 取 MAC，转大写、去掉分隔符（`AA:BB:CC` → `AABBCC`）
3. 按接口名排序（保证跨次运行稳定）
4. 依次拼接，**不带分隔符**
5. 对拼接结果做 MD5

### 2.2 卷序列号的规范化

序列号是 32 位整数，格式化为 8 个十六进制字符，**故意混用大小写**：

```
fmt: "%02x%02X%02x%02x"     // 例：1a2B3c4d
```

这个混用是为了**兼容原客户端的既有行为**（服务端按原客户端的输出登记过），实现时照抄，不要"修正"成统一大小写。

## 4. 缓存

路径 `~/.config/vpnkit/device-id`，内容就是那 32 个字符，权限 `0600`。

规则：

- 读到即用，**不校验来源**
- 文件内容非法（长度/字符集不符）时视为不存在，重新计算
- `devid pin <value>` 写入指定值；`devid pin` 不带值时固化本机当前算出的值（§5 推荐用法）；`devid show` 打印当前值及来源

## 5. 本机标识持久化（重要）

原客户端每次实时计算标识，本机插拔扩展坞、启用虚拟网卡等变化会让同一台机器算出不同的值。因此：

> **推荐做法：本机首次成功登记后，用 `devid pin` 把本机的标识持久化，之后本机始终发送同一个值。**

这样做的效果：本机的外设变化不再导致本机被误判为新设备。

使用边界：

- `devid pin` 只用于持久化**本机自己**的标识；不得把一台机器的标识拿到其他机器上使用，那属于绕过网关管理方的设备绑定策略
- 使用本工具前应取得网关管理方对第三方客户端的认可

需要注意：

- 固化值属于身份凭据，按 `AGENTS.md` 的红线要求，不进仓库、不打日志
- 若管理员侧解除了绑定，固化值会失效，需要重新走一次登记流程

## 6. 隐私说明

设备标识可反推硬件信息（MAC 前缀含厂商）。因此：

- 只在登录流程中发送，不做其他用途；是否发送由 `auth.send_device_id` 决定（`docs/09` §3）
- 绑定申请（`docs/02` §4.2）**默认关闭**：它会把本机登记进网关的设备绑定队列，是有副作用的写操作
- 登录表单字段名原始资料未给出（TODO(待实测)），取 `auth.device_id_field`，默认 `devid`，发送时打 `assumption=device_id_field`
- 网关要求 `auth/hid` 二次认证时另走一次提交：`POST auth.hid_endpoint`（默认 `/por/login_hid.csp`），
  表单字段 `auth.hid_field`（默认 `hid`），只带特征码本身，见 `docs/02` §4.1
- 若该步认证不过（设备未绑定），再发一次绑定申请：`POST auth.submithid_endpoint`（默认 `/por/submithid.csp`），
  参数走查询串，除特征码外还带本机 `macaddress`（`devid.PrimaryMAC`，大写冒号分隔）与 `hostname`（`os.Hostname`），
  见 `docs/02` §4.2。绑定申请会把机器送进管理员审批队列，因此只由 `auth.register_device` 显式开启
- `auto` 依据**上次登录**缓存在会话文件里的 `Other.isHidUser`：`isHidUser` 来自 `conf.csp`，只有登录之后才拿得到
- 日志里掩码显示（保留首尾各 4 字符）
- `status --json` 默认不包含该字段，需显式 `--show-devid`

## 7. 测试

| 用例 | 期望 |
|---|---|
| 有缓存文件 | 直接返回缓存值，不枚举网卡 |
| 缓存文件内容为 31 字符 | 视为无效，重新计算 |
| 无物理网卡 | 退化到卷序列号 |
| 无网卡且无卷序列号 | 返回 `ErrNoFingerprintSource`，不返回空串 |
| 输出格式 | 恒为 `[0-9A-F]{32}` |
