# 05 · 密码学原语

本项目的密码学是**兼容性约束**，不是安全设计目标。四个原语，全部标准库可实现。

## 1. RSA · PKCS#1 v1.5（认证）

| 项 | 值 |
|---|---|
| 用途 | 加密密码 |
| 填充 | PKCS#1 v1.5（**不是** OAEP） |
| 密钥来源 | 服务端下发十六进制模数 n 与指数 e |
| 编码 | 密文转**大写**十六进制 |

```go
func EncryptPassword(password, csrf, nHex, eHex string) (string, error) {
    n, ok := new(big.Int).SetString(nHex, 16)
    if !ok { return "", ErrBadPublicKey }
    e64, ok := new(big.Int).SetString(eHex, 16)
    if !ok { return "", ErrBadPublicKey }
    pub := &rsa.PublicKey{N: n, E: int(e64.Int64())}

    plain := []byte(password + "_" + csrf)
    if len(plain) > pub.Size()-11 {
        return "", ErrPasswordTooLong   // 不要截断
    }
    ct, err := rsa.EncryptPKCS1v15(rand.Reader, pub, plain)
    if err != nil { return "", err }
    return strings.ToUpper(hex.EncodeToString(ct)), nil
}
```

边界：

- 模数 1024 位 → 明文上限 117 字节；2048 位 → 245 字节
- 指数常见 `10001`
- n 为奇数、长度非标准时要报错，不要静默改用默认值

## 2. MD5（设备标识、验证码）

| 用途 | 输入 | 输出 |
|---|---|---|
| 设备标识 | 规范化要素串 | 32 位**大写**十六进制 |
| 图形验证码 | 用户输入 | 32 位十六进制（大小写以服务端为准） |

MD5 在此仅用于"生成稳定短标识"，不是安全摘要。不要用它做任何认证校验。

## 3. RC4（数据面）

### 3.1 算法

标准 RC4，`crypto/rc4` 可直接用：

```go
type RC4State struct {          // 状态跨包连续
    i, j byte
    s    [256]byte
}
```

标准实现的语义等价于：

```
i = (i + 1) & 0xff
j = (j + S[i]) & 0xff
swap(S[i], S[j])
out ^= S[(S[i] + S[j]) & 0xff]
```

### 3.2 使用约束

| 约束 | 说明 |
|---|---|
| **状态连续** | 初始化一次，之后每个包接着上一个包的 i/j/S 继续，**不能每包重置** |
| 方向独立 | 上行与下行各一个独立状态实例 |
| 只加密负载 | 12 字节帧头不参与 |
| 就地变换 | 长度不变，可原地 XOR |

```go
// 每帧
st.XORKeyStream(pkt[12:], pkt[12:])
```

### 3.3 密钥来源

`SEND_IP` 的 `enc` 字段决定是否启用。密钥由握手会话派生——因为握手模板是固定的（`docs/03` §2），
**密钥对所有持有本程序的人都是确定的**。

### 3.4 实现建议

第一版可以只实现**不加密**路径（`enc == 0`），把 RC4 留作独立可测模块。
联调时若服务端要求加密，再打开。两条路径都要有单元测试，用已知向量验证。

## 4. 安全声明（必须写进文档和 README，不要美化）

1. 握手使用预置会话凭证，**不做前向保密**。
2. RC4 已被密码学界证明不再安全，且此处密钥可由程序本身确定。
3. 因此这套加密**只提供流量混淆，不提供机密性**。任何拿到本程序或能抓包的人都能还原内容。
4. 不要把本工具用于传输确实需要保密的数据；它的价值在**分流与易用性**，不在加密。

如果要提升机密性，正确做法是走另一条传输（例如在隧道之上再套一层自有 TLS/QUIC），
而不是修改本协议——改了就联不通。

## 5. 测试向量

`pkg/wire` 的测试必须包含：

| 用例 | 输入 | 期望 |
|---|---|---|
| RSA 加密长度 | 模数 1024 位 | 密文 128 字节 → 256 字符 hex |
| RSA 明文超长 | 118 字节明文 + 1024 位模数 | 返回 `ErrPasswordTooLong` |
| MD5 大小写 | `"abc"` | `900150983CD24FB0D6963F7D28E17F72` |
| RC4 连续状态 | 两个包连续加密 | 与一次性加密两个包拼接结果一致 |
| RC4 重置错误 | 每包重置状态 | 测试应能捕获该错误 |
